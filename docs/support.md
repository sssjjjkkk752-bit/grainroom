# Grainroom 支持

Grainroom 是免费开源的 iPhone 胶片相机、暗房、观片台和黑白制片工具。

遇到问题时，请通过 [GitHub Issues](https://github.com/sssjjjkkk752-bit/grainroom/issues) 报告，并附上：iPhone 型号、iOS 版本、应用版本、操作步骤与错误提示。请勿公开私人照片、DNG 原片、定位信息或账号凭据。

48MP、ProRAW 和 RAW 格式取决于当前镜头与设备 API 能力。界面显示请求上限，拍摄后以实际尺寸为准。原始 RAW 导出不包含暗房效果，胶片效果需导出为成片。

项目尚未提交 App Store，真机拍摄与低内存设备的全尺寸性能仍需验证。
