# Grainroom 0.3 验证记录 · 2026-11-01

环境：Xcode 27.2 / iOS SDK 27.2 / iOS Simulator 27.2，Apple Silicon Mac，Rust 1.99.1，CPU f64 后端。

## 本版 iOS 集成测试：8 项全部通过

1. **48MP HEIF 导出**：8064×6048 测试图，关闭胶片效果与片边，输出保持相同尺寸。验证尺寸与编码路径，不代表已经验证真实相机或 48MP 全特效性能。
2. **全部成片编码器**：HEIF、JPEG、PNG、TIFF 加片边和日期均成功；PNG / TIFF 检查到 16 位深度。
3. **取消导出**：已经取消的任务停止并返回 CancellationError。
4. **自制黑白光谱响应**：更改红 / 蓝波段感度，在相应色块上产生显著不同的实际引擎输出。
5. **图库与原始文件**：图库重新载入保留记录；原始文件导出与输入逐字节一致，JSON 配方可解码。
6. **整图 / 分块对照**：1100×700 图像关闭空间效果后，全图光谱与分块光谱采样点误差不超过 2/255。
7. **片幅和日期背**：画幅裁切、即影即有画布和文字组合有效。
8. **分块坐标 / 原尺寸 / 16 位**：1031×691 非整块尺寸图检查拼块边界与方向，像素误差不超过 1/255，输出为 16 位 PNG。

最终模拟器测试：`studio-ios-tests.log`，TEST SUCCEEDED。
最终 iPhone arm64 未签名 Release 编译：BUILD SUCCEEDED。
